## Decisions other documents depend on

- **Positioning:** Sabre sells the postcode, not the house. *You picked this street.*
- **Entry offer:** a free check of the block against Brisbane's Traditional Building
  Character Overlay. It qualifies and disqualifies in five minutes.
- **The look does not get redesigned.** Palette and type stay as
  `site/docs/design-system.md` defines them; red drops back to an accent.
- **No Meta spend before real footage exists.** Running ads built on AI stand-ins
  means paying twice — once to run them, once to replace them.
